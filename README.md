# To-Do App

[DEMO LINK](https://itisandrew25-ship-it.github.io/To-Do-App/)

## 📌 Project Description

A modern task management application (To-Do List) built with React, TypeScript, and Vite. Allows users to add, edit, delete, and filter todos with a clean and responsive interface styled with Bulma and SCSS (BEM methodology).

## Key Advantages & Features:

- **Responsive Layout:** Adaptive design ensuring a seamless user experience across mobile devices, tablets, and desktops.
- **Scalable Architecture:** Built using React functional components with TypeScript and a modular SCSS structure following the **BEM methodology** for clean, maintainable, and reusable styles.
- **Interactive Enhancements:** Smooth user interactions with animations powered by React Transition Group.
- **Task Management:** Add new todos, mark them as completed, edit titles, delete individual items, and clear all completed tasks.
- **Filtering:** View All, Active, or Completed todos with URL-based filter navigation.
- **Error Handling:** User-friendly error notifications with auto-dismiss and manual close.
- **Loading States:** Visual feedback during async API operations.
- **Optimized Performance:** Automated build workflow and asset optimization handled via **Vite**.
- **Code Quality:** Strict adherence to code standards maintained using **ESlint**, **Prettier**, and **Stylelint**.
- **Testing:** End-to-end tests configured with **Cypress**.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/itisandrew25-ship-it/To-Do-App.git
   cd To-Do-App
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the project locally:
   ```bash
   npm start
   ```

4. Build for production:
   ```bash
   npm run build
   ```
